# Datasets subdirectory

This subdirectory is tasked with enhancing the organizational structure of the transmitted data in this pipe-and-filter and service-oriented architecture. Furthermore, this folder is a parent of its two categorized children:

* **API Data:** The .csv files retrieved in the query to opendlv-view's functionality of downloading the csv files of a specific .rec file

* **Pipeline Data:** The CSV files contained the data that have been filtered through the Detection- and Algorithmic- Services
